# 约束：必须停下来确认的边界

> 课程图 27/40：**关键问题未确认就停止推进**，而不是先写一版再让业务承受返工。
> 这些边界由 E1 工程闸门机器判定，不是"请注意"式提醒。

## 必须停下来确认

1. **影响范围答不上来**：说不清会影响哪些已有接口/表/任务 → 停止，先查清调用方；
2. **需求依据缺失**：没有已确认的 PRD 或来源链（谁、何时、在哪句话里提出）→ 停止，先走澄清；
3. **口径未定**：聚合维度、时区、字段范围、权限角色未确认 → 停止（口径错了，页面能跑也没用）；
4. **回滚方式未定**：变更类改动（含数据迁移）没有回滚步骤 → 停止；
5. **权限边界不清**：谁能看、谁能改未定义 → 停止。

## 禁止动作（无论是否"看起来更合理"）

- 禁止用"AI 认为更合理"取代项目既有决定（含命名、协议、目录约定）；
- 禁止删除或重命名既有表/字段/接口，除非有明确迁移与回滚方案；
- 禁止在未确认授权的情况下执行对外承诺（工期、价格、SLA）；
- 禁止越过工程闸门（E1/E2/E3）直接进入下一步——闸门返回 `blocked=true` 就是必须停。
