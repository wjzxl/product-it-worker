Residual risk

  • 本次全部测试在无真实 LLM Key 的模板桩下执行：AI 生成内容的质量、提示注入抵抗力、成本准确性均未验证。
  • 知识库使用 HashEmbedder 哈希桩（无 Qdrant），检索质量与向量维度契约未验证。
  • GitLab / 飞书真实外呼未打通，MR 合入、回调签名（gitlab-bridge 的 HMAC 实现）与通知链路未做端到端验证。
  • 隔离实例使用一次性 sqlite，Postgres 特有行为（并发、连接池、行锁）与生产编排（Caddy/SSO/多容器）未覆盖。
  • 性能仅在 20 并发下测量 approval-gateway 的读取路径，p95 278ms 距 300ms 预算仅 7% 余量，写入路径与更高并发未压测。
  • 未做并发/竞态测试：侦察指出 decide、im_card_callback、sweep 均为无锁读改写，可能产生重复决策与重复事件，本次未复现。
  • 跨租户读取在 approval-gateway 的 GET 路径上被正确拒绝（SEC-002 通过），但写路径存在缺口（SEC-003），说明隔离是逐路径实现的，未系统性保证，可能存在本次未枚举到的其它缺口。
