## 11. Residual risk and what was not tested

**Residual risk**

- 【发布阻断】DEF-008（MAJOR，未修）：服务令牌与人类 Bearer 同带被判 401 → 驾驶舱点批准实测 502、人类凭据 /resume 409；平台自身 resume 用服务凭据可绕过。
